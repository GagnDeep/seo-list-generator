# Changelog

## 0.1.0 (2026-04-02)

- Initial release
- `ai-ops init` — initialize database
- `ai-ops track` — track AI API calls with cost calculation
- `ai-ops dashboard` — terminal cost dashboard with ASCII charts
- `ai-ops report` — JSON/CSV cost reports
- OpenAI and Anthropic cost calculation built-in
- SQLite local storage (no cloud, no account needed)
