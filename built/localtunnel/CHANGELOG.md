# Changelog

All notable changes will be documented in this file.

## [1.0.0] - 2026-04-01

### Added

- `tunnel connect <port>` — expose a local port via tunnel
- `lt-server` — self-hosted tunnel server
- `--subdomain` flag for custom subdomain requests
- `--auth` flag for basic auth protection
- TypeScript library with full type definitions
- WebSocket-based tunnel protocol
- HTTP proxy with proper header forwarding
- Subdomain allocation with collision detection
- Global auth support on server
- Unit tests with Vitest
