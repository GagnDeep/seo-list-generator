### 3. CONTRIBUTING.md
```markdown
# Contributing to awesome-[SLUG]

Welcome! This list follows the [awesome manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md).

## Contribution Guidelines

1. **Search first** - Ensure your suggestion isn't already in the list
2. **Quality over quantity** - One great tool > ten mediocre ones
3. **Include all fields** - Name, URL, description (80-150 words), category tags
4. **Verify URLs** - Only submit working links
5. **Unique descriptions** - Write original descriptions, don't copy marketing copy

## How to Contribute

1. Fork this repo
2. Add your item to the appropriate category in README.md
3. Follow the format: `#### [Tool Name](url)` with description block
4. Submit a PR with a brief explanation

## Quality Standards
- Description must be 80-150 words
- Must have real, working URL
- Must have category tags
- Be objective - describe what it does, not just praise
```
