# AI Fitness Assessment Tool

## What
Open source fitness assessment tool that takes client measurements, fitness tests, and generates baseline programs and progress tracking.

## Why
Personal trainers need assessment tools but most are proprietary or require subscriptions. Creating a baseline is the first step in any programming — shouldn't require expensive software.

## Market Gap
- PTDistributor: Outdated Java applet
- TrainHeroic: Assessment included but $30+/month
- NASM CPT app: Only for their certification holders
- **Gap**: Free, open assessment tool that generates actionable baselines

## Tech Stack
- **Frontend**: JavaScript/TypeScript
- **Framework**: Could be vanilla TS or React (lightweight)
- **Storage**: LocalStorage or SQLite
- **Export**: PDF reports, CSV data export
- **AI**: Optional AI program generation from assessment results

## What's Close
- [ACSM](https://www.acsm.org) - Resources but no software
- [NSCA](https://www.nsca.com) - Resources, no tools
- [ExRx](https://exrx.net) - Great resource but static
- [Google Forms templates](https://forms.google.com) - Manual, no logic

## Revenue Model
- Free for trainers (self-hosted)
- Premium templates for specific populations (seniors, athletes)
- Integration with gym management systems
