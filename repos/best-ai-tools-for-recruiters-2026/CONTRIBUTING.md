# Contributing to Best AI Tools for Recruiters 2026

Thank you for your interest in contributing!

## How to Contribute

### Adding a Tool

1. **Fork this repository**
2. **Add your tool** to the appropriate category in `README.md`
3. **Ensure the tool meets these requirements:**
   - AI-powered tool for recruiting, HR, or talent acquisition
   - Must have a valid GitHub URL
   - Include accurate information (stars, license, description)
4. **Submit a Pull Request**

### Tool Submission Requirements

When adding a tool, include:
- **GitHub URL** (required - must be a real repository)
- **80-150 word description** explaining what the tool does
- **Category tags** (e.g., resume-screening, chatbot, ats)
- **Stars count, primary language, and license** from GitHub

### Categories

- AI Resume Screening & Parsing
- AI Candidate Sourcing
- AI Interview Tools
- AI Job Matching
- AI Chatbots for Recruiting
- ATS with AI Features
- AI Sourcing & Boolean Tools

### Quality Standards

- Only submit open-source or publicly available tools
- Ensure all GitHub links are working (HTTP 200)
- Tools must be directly relevant to recruiting/HR work
- No generic tools unless specifically designed for recruiting

## Reporting Issues

Found a broken link or outdated information? Please open an issue and we'll fix it promptly.

## Code of Conduct

Be respectful and constructive. We're here to build a valuable resource for the recruiting community.
